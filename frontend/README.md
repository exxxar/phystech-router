# Путеводитель по кафедре компьютерных технологий

Интерактивный клиентский путеводитель по пространству кафедры. Построение маршрутов, персональные рекомендации, работа offline.

## Стек

- Vue 3 (Options API + composable-функции)
- Vue Router 4
- Pinia
- TypeScript
- Bootstrap 5
- PWA (vite-plugin-pwa)
- Vite

## Запуск

```bash
npm install
cp .env.example .env
npm run dev
