# Backend интерактивного путеводителя по кафедре

Полноценный REST API сервер для клиентского приложения (Vue 3 PWA).

## Стек технологий
- Node.js, TypeScript, Express.js
- PostgreSQL, Prisma ORM
- JWT, bcrypt, Zod (валидация)
- A* и Dijkstra (кастомные реализации алгоритмов)
- Pino (логирование), Helmet, CORS
- Vitest, Supertest (тестирование)
- Docker
